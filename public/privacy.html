Privacy Policy

Last updated November 7, 2026

Sosumi is a free service that converts Apple Developer documentation to Markdown. It has no accounts, and it doesn't ask for your name, email address, or other personal information. This page applies to the website, the HTTP API, and the MCP server at https://sosumi.ai/mcp.

What Sosumi keeps

Sosumi doesn't set cookies. It doesn't have a database, and it doesn't save the requests it receives or the pages it returns.

Sosumi runs on Cloudflare Workers with Workers Logs turned on. For each request, Cloudflare logs the request's URL and other request and response details, and it logs any errors that Sosumi reports. A URL can include what you asked for, such as a documentation path or a search query. Cloudflare keeps these logs for up to 7 days. Sosumi's maintainers can read them to find and fix problems.

Who receives your requests

To answer a request, Sosumi's servers fetch the page from developer.apple.com or send your search query to Apple's documentation search service. For an external Swift-DocC page, Sosumi fetches from the host in the URL you give. Those services receive the path, query, or URL from Sosumi's servers. Sosumi makes these requests with its own headers. It doesn't forward your IP address, cookies, or request headers.

When you use Sosumi through an MCP client or plugin, your client sends Sosumi the tool's input, such as a search query, documentation path, or URL. Sosumi handles that input in the same way as any other request.

Responses include Cache-Control headers. Cloudflare, your client, and proxies between you and Sosumi can keep a copy of a response for as long as those headers allow. For documentation and search responses, that is at most 24 hours.

The home page shows Cursor's install button images, which load from cursor.com. When you view the home page, your browser requests those images from Cursor.

The sosumi command-line tool runs on your computer. It fetches documentation directly from Apple and doesn't send requests to sosumi.ai.

Monitoring

A separate monitoring service checks that sosumi.ai works every 5 minutes. It saves whether the last check passed. When a check fails or recovers, it saves an alert email with the check's error message until the email is sent to the maintainers. It doesn't save anything about visitors.

Changes and questions

When this policy changes, the date at the top of this page changes too. The page's history is public in the sosumi.ai repository. For questions, see Support.
